# Contributing

Open an issue first and describe the bug or the change you have in mind. A pull request without a linked issue may be closed.

- Bugs: include the browser, a minimal HTML snippet and what you expected.
- Features: explain the use case. Iris keeps a small API, so many requests will be declined.
- Security problems: do not open an issue, see [SECURITY.md](.github/SECURITY.md).

Before you open a pull request, run `npm run check`. It runs Stylelint, Prettier, the build and the tests.
